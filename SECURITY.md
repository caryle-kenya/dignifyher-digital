# Security

This is a concept-stage repository. No production service or security response team is currently documented.

## Reporting a concern

Please do not publish vulnerabilities, credentials, personal data or sensitive health information in a public issue. A verified private reporting contact will be added after the project owner confirms it. Until then, raise the need for a secure reporting channel with Caryle Enterprises through its verified organisational contact.

## Safe development

- Never commit passwords, API keys, tokens, private keys, database credentials or personal data.
- Keep local secrets in environment variables or an untracked local configuration file. Use dummy values in examples.
- Use fictional data for demonstrations; do not use real reproductive health conversations without appropriate consent, lawful basis, de-identification and safeguarding review.
- Limit access to people who need it and enable multi-factor authentication on repository accounts.
- If a secret is committed, notify the project lead promptly. Removing it from the latest commit may not remove it from repository history.
