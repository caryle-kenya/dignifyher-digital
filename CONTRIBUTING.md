# Contributing

This document is a starting point and requires Caryle Enterprises' review before accepting public contributions.

## Before contributing

- Discuss substantial changes with the project maintainers through an issue or pull request.
- Do not submit personal or health information, credentials, proprietary manufacturing information, or copyrighted material without permission.
- Use fictional data in examples.
- Keep claims about implementation, testing, clinical review, partnerships and impact tied to evidence.
- Do not present the concept as a diagnosis or treatment service.

## Changes

Use clear commit messages and focused pull requests. Explain what changed, why it is needed, and how it was checked. Request maintainer review before merging. A final contribution workflow will be published after repository ownership and maintainers are confirmed.

## Licence

The project licence is pending owner approval. Until the approved licence is added, do not assume that repository materials are licensed for reuse.
