# Proposed 12-month implementation plan

This is a planning sequence derived from the project brief. Calendar dates, owners, budgets and evidence of completion must be agreed by Caryle. No milestone is represented as completed.

| Sequence | Proposed work | Deliverable / evidence |
|---|---|---|
| Months 1–2 | Community consultation and user research in Kisumu County | Approved research plan, consultation summary and documented design needs |
| Months 2–4 | Co-design, requirements and architecture decisions | Reviewed user journeys, requirements and architecture decision records |
| Months 3–6 | Build a bounded functional prototype | Versioned prototype with setup documentation and safety limitations |
| Months 4–7 | Develop and validate English, Kiswahili and Dholuo educational content | Reviewed content set with sources, review roles and version history |
| Months 5–8 | Assess privacy, security, data protection and adolescent safeguarding | Approved assessments and documented controls before personal data collection |
| Months 7–9 | Evaluate channel feasibility and implement selected access channel(s) | Working integration only if selected, tested and approved |
| Months 9–10 | Pilot in selected communities, subject to required approvals | Pilot report with actual methods, participants, feedback and limitations |
| Months 10–11 | Refine based on evidence | Updated prototype and change log |
| Months 11–12 | Prepare open-source release and scale-up strategy | Owner-approved licence, public documentation, repository review and partnership strategy |

Assign a named owner, target date, dependencies and acceptance evidence to each milestone before execution. Pilot activity depends on appropriate approvals, community readiness, safeguarding and privacy controls.
