# DignifyHer Digital browser demonstration

## Run it

Open `index.html` in a current desktop or mobile browser. No installation, account, server, or internet connection is needed to use the on-page demo. Internet access is needed to follow public reference links and load the optional web fonts; system fonts are used as a fallback.

## What works

- Browse a small set of fixed learning topics.
- Choose a suggested question or type a general question; the page matches it to a prepared topic and shows a bounded response.
- Use the navigation and topic buttons on desktop or mobile layouts.
- Follow links to public sources used for sample information.

The question matching happens in the browser. Text is not transmitted to a service and is not saved by this demo. It disappears when the page is refreshed or closed.

## Limits

This is an interface prototype, not a clinical service. Its small English-only content set is for demonstration and requires review by Caryle and qualified health reviewers before community use. Topic matching is limited; unmatched questions receive a safe fallback. There is no personal assessment, diagnosis, treatment, cycle tracking, account, referral directory, messaging-channel connection or community test result.

Use fictional questions only. Do not enter names, contact details or personal health information.
